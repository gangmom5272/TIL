## Data Engineering

### 오늘 읽은 내용

견고한 데이터 엔지니어링에서 보안, 최소 권한 원칙, 데이터 거버넌스, 데이터 품질, 데이터 모델링에 관한 내용을 읽었다.

### 최소 권한 원칙

사용자나 시스템에는 의도한 기능을 수행하는 데 반드시 필요한 데이터와 자원에만 접근할 수 있도록 권한을 부여해야 한다.

최소 권한 원칙을 적용하면 실수로 데이터를 변경하거나 삭제하는 우발적인 사고를 줄이고, 보안 사고의 피해 범위를 제한할 수 있다.

### 데이터 거버넌스

데이터 거버넌스는 적절한 보안 제어로 데이터를 보호하고 조직 전체의 데이터 가치를 극대화하기 위해 인력, 프로세스, 기술을 활용하는 체계이다.

### 데이터 품질

- 정확성: 데이터가 실제 사실과 일치하고 올바른가?
- 완전성: 필요한 데이터가 빠짐없이 기록되어 있는가?
- 적시성: 필요한 시점에 최신 데이터를 사용할 수 있는가?

### 데이터 모델링

데이터 모델링은 현실의 대상과 관계를 데이터로 표현하고, 데이터를 저장하고 활용할 수 있는 구조로 설계하는 과정이다.
