# 보안과 데이터 관리

## 오늘 읽은 내용

견고한 데이터 엔지니어링에서 보안과 데이터 관리에 관한 내용을 읽었다.

## 핵심 키워드

- 보안
- 최소 권한 원칙
- 데이터 관리
- 데이터 거버넌스
- 데이터 품질
- 데이터 모델링

## 보안

데이터 엔지니어링에서는 데이터가 수집, 저장, 변환, 제공되는 모든 단계에서 보안을 고려해야 한다.

### 최소 권한 원칙

최소 권한 원칙은 사용자나 시스템이 의도된 기능을 수행하는 데 반드시 필요한 데이터와 자원에만 접근할 수 있도록 권한을 부여하는 원칙이다.

불필요한 접근 권한을 제한하면 실수로 데이터를 변경하거나 삭제하는 우발적인 사고를 줄일 수 있고, 보안 사고가 발생했을 때 피해 범위도 제한할 수 있다.

## 데이터 관리

데이터 관리는 조직이 데이터를 안전하고 신뢰할 수 있는 상태로 유지하면서 효과적으로 활용하기 위한 활동이다.

데이터 거버넌스, 데이터 품질, 데이터 모델링 등이 데이터 관리에 포함된다.

## 데이터 거버넌스

데이터 거버넌스는 적절한 보안 제어로 데이터를 보호하고 조직 전체의 데이터 가치를 극대화하기 위해 인력, 프로세스, 기술을 활용하는 체계이다.

누가 어떤 데이터에 접근할 수 있는지, 데이터의 책임자는 누구인지, 데이터를 어떤 기준으로 관리할지와 같은 규칙을 정하고 운영한다.

## 데이터 품질

데이터 품질은 데이터를 신뢰하고 목적에 맞게 사용할 수 있는지를 나타낸다.

### 정확성

데이터가 실제 사실과 일치하며 올바른 값을 가지고 있는지를 의미한다.

### 완전성

필요한 데이터가 빠짐없이 기록되어 있는지를 의미한다.

### 적시성

필요한 시점에 최신 데이터를 이용할 수 있는지를 의미한다.

## 데이터 모델링

데이터 모델링은 데이터를 사용 가능한 형태로 구조화하는 과정이다.

현실의 대상과 관계를 데이터로 표현하고, 데이터를 어떤 테이블과 컬럼으로 구성할지 설계한다. 적절한 데이터 모델은 데이터를 일관되게 저장하고 조회하며 활용할 수 있도록 돕는다.

## 핵심 정리

- 최소 권한 원칙은 필요한 범위에서만 접근을 허용해 우발적인 사고와 보안 피해를 줄인다.
- 데이터 거버넌스는 인력, 프로세스, 기술을 활용해 데이터를 보호하고 데이터의 가치를 높이는 체계이다.
- 데이터 품질은 정확성, 완전성, 적시성 등의 기준으로 판단할 수 있다.
- 데이터 모델링은 데이터를 저장하고 활용할 수 있는 구조로 설계하는 과정이다.
